# PC-DMIS Field Kit store site

Static site for GitHub Pages. Generated; edit the generator rather than the HTML.

- Set GitHub Pages to deploy from the main branch root.
- If you add a custom domain, update BASE in the generator, then sitemap.xml and canonical links follow.
- Visit tracking: GoatCounter (robbmxstore.goatcounter.com).
- Buy links point to robbmx.gumroad.com/l/<slug>; set each Gumroad product's custom URL to the slug.
